An Android app for the Hermes you already run.

Every Hermes profile becomes a bot with its own face. Chat with it, watch what it’s doing, and approve risky commands from your phone. It talks only to your server.

What is it, exactly?

A phone client for Hermes Agent, the open-source agent from Nous Research. You run Hermes on your own machine (bare metal, Docker, an Incus container, a VPS, a Pi) and the app connects to its API server over HTTPS. Nothing goes through a third-party service.

Each Hermes profile shows up as a bot. Your primary bot sits large at the top of Home; the rest are listed with their last message, unread count and what they’re doing right now.

  • AtlasYour main agent. Plans your day, keeps notes
  • ForgeNeeds your OK
  • NovaWatches the markets and your watchlist

Sample bots from the app’s built-in demo mode. You can create bots from the phone too: name, persona, model and look.

Why do they have faces?

So you can tell what a bot is doing at a glance. A face only changes when the chat says so: it never looks busy, pleased or expectant unless it is.

  • IdleNothing going on
  • ListeningYou’re typing
  • ThinkingA run started
  • WorkingA tool is running
  • WaitingNeeds your OK
  • SuccessA reply landed
  • ErrorThe run failed

Each bot blinks and breathes at its own uneven rhythm, so a row of them never moves in step. Pick from eight shapes, a dozen colours and four eye styles. Faces pause off-screen and stay still with Android’s Remove animations setting.

Can I see what it’s doing?

Searching the web for What can you do?

Yes. While a reply is being worked on, a live line says what’s happening, built from the run’s own events. Each tool call becomes a step you can open to see the command and its output.

Replies stream with markdown, tables and copyable code. Type while it’s working to steer it, or tap stop. If the connection drops, the app reconnects and resumes the same run without sending your message twice.

Will it run things without asking?

Not the things Hermes is set to ask about. When a command needs your OK, the run pauses and a card explains what it wants to do.

The card only clears after Hermes accepts your answer. Approvals also arrive as notifications with Allow and Deny buttons, and Hermes’s own approval settings still apply to everything the app sends.

What else can I do from the phone?

Attachments
Photos, camera or files. Images go inline; text files (code, CSV, JSON, Markdown) as text.
Routines
Hermes cron jobs: list, run now, pause, resume, delete.
MCP servers
Add, enable, test, or install from Hermes’s catalog.
Plugins and skills
Browse and toggle plugins, skills, toolsets, the memory provider and the persona (SOUL.md).
Gateway notices
A finished background job or a delivered routine shows as a small chip in the chat.
Voice
Dictation in the composer, read aloud, and a simple voice-call screen.
Privacy
Quiet hours, “New reply”-only notifications, and an optional fingerprint or screen-lock app lock.
History
Search in a chat, older sessions, export as Markdown, reactions, quote-reply, edit and resend.

Routines, MCP, plugins, skills and memory need the optional hermes-bridge. Chat works without it.

How does it reach my server?

Over HTTPS, through whatever you already use to reach your machine from outside.

How do I set it up?

  1. Turn on the Hermes API server. Add these to ~/.hermes/.env on the machine that runs Hermes, then restart the gateway. 
    API_SERVER_ENABLED=true
API_SERVER_HOST=127.0.0.1
API_SERVER_PORT=8642
API_SERVER_KEY=$(openssl rand -hex 32)
  2. Reach it over HTTPS. Tailscale Funnel needs no domain or open ports: 
    sudo tailscale funnel --bg --https=443 http://127.0.0.1:8642
    A reverse proxy with TLS on your own domain works the same way.
  3. Install the APK. Download it from the latest release and allow Install unknown apps for your browser. Updates install over the old version.
  4. Connect. In Settings → Connection, enter your server URL and API key. The app checks both before saving and tells you which one is wrong.

What doesn’t it do?

  • No push server. Notifications work while the app runs in the background. Swipe it away and it can’t notify you.
  • Android only. iOS isn’t built or tested.
  • Not a dashboard replacement. Kanban, the terminal, the file browser and config editing stay in Hermes’s own dashboard or CLI.
  • Images and text only. PDFs and other binary files aren’t supported by the API yet.

It’s an early, personal project used daily against a real Hermes. Expect rough edges; issues and pull requests are welcome.
